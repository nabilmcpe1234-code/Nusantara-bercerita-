README - Cara pakai (quick)
Files included:
- index.html
- styles.css
- app.js

Cara pakai offline (paling mudah):
1. Download dan ekstrak file zip.
2. Pastikan ketiga file berada di folder yang sama.
3. Buka file index.html menggunakan browser (Chrome/Firefox).
4. Jika tidak muncul, klik kanan > Open with > Chrome (atau 'Buka dengan' di HP).

Catatan teknis:
- Semua data (cerita) disimpan di localStorage browser. Jika ingin menghapus semua data, buka console (F12) dan jalankan:
  localStorage.removeItem('tkb_stories_v1');
- Password admin default: admin123 (ubah di app.js sebelum dipakai publik).
